# Aurora Vane // 2026 Comparative Literature & Digital Humanities Codex

An avant-garde, futuristic digital portfolio and literary codex designed for an English Major / Digital Humanities Scholar (**Aurora Vane, Harvard '26**), featuring interactive essay glossing & margin annotations, ambient Web Audio soundscapes, a 3D Curator Bookshelf, and a full-featured content **Admin Portal**.

---

## ✨ Features

- **2026 Kinetic Editorial Aesthetics**: 4 switchable visual themes (*Obsidian Ink*, *Parchment*, *Cyber Gothic*, *Liquid Gold*), kinetic header, live EST clock, and glassmorphism UI.
- **Distraction-Free Essay Reader**: Full modal reading room with customizable font sizes, typography selectors (*Playfair Serif*, *Inter Sans*, *Space Mono*), line spacing controls, and copy/print support.
- **Interactive Glossing & Annotations**: Highlighted literary terms dynamically open margin notes, theoretical references, and historical contexts.
- **Curator's Reading Matrix**: 3D book spine cards with live reading progress bars (0-100%), star ratings, status tags (`Finished`, `Currently Reading`), and curator reviews.
- **Built-in Web Audio Synthesizer**: Pure JavaScript audio generator for ambient Rain, Binaural Focus drone, and mechanical typewriter feedback.
- **Administrative Portal**: Complete password-protected content management dashboard (`admin2026` or 1-click Quick Unlock) to add, edit, or delete works, update bookshelf items, adjust author biography, and export/import JSON database backups.

---

## 🛠️ Tech Stack

- **Framework**: Vite + React 18
- **Styling**: Vanilla CSS Design System with CSS Variables, Glassmorphism, and Fluid Grid
- **Icons**: Lucide React
- **Audio**: Web Audio API
- **State**: React Context + `localStorage` persistence

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 3. Accessing the Admin Portal
- Click **"Admin Portal"** in the navigation bar or footer.
- Enter passcode: `admin2026` (or click **Instant Quick-Unlock** in demo mode).
